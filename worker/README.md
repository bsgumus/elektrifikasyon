# elektrifikasyon.org API worker

A single Cloudflare **Module Worker** that serves only `/api/*` for the static site
(GitHub Pages). Every other request is `301`-redirected to the site. The worker is
stateless: **no KV, R2, D1, Durable Objects, cron triggers or secrets** — only two
optional plain-text environment variables.

## Layout

| Path | Role |
|---|---|
| `src/model-data.js` | **All** model coefficients and base-year data (ETKB 2024 balance r1, thousand toe; 1 ktoe = 11.63 GWh). The only file to touch when the model changes. |
| `src/index.js` | Logic only: solver, routes, CORS allowlist, rate limiter. Contains no model numbers (the bundler enforces this). |
| `dist/worker.js` | Single-file bundle generated by `tools/bundle_worker.py`. Do not edit by hand. |
| `wrangler.toml` | Deployment config with default `[vars]`. |

## Deploy

**A) wrangler** (uses `src/index.js` + `src/model-data.js` as ES modules):

```sh
cd worker && npx wrangler deploy
```

**B) Dashboard paste** (no Node/wrangler needed):

```sh
python3 tools/bundle_worker.py          # regenerates worker/dist/worker.js
```

Then Cloudflare dashboard → Workers → your worker → *Edit code* → paste the whole
of `dist/worker.js` → *Deploy*. Variables can be set under *Settings → Variables*;
if none are set, the compiled-in defaults apply.

Keep `dist/worker.js` committed and current: `python3 tools/bundle_worker.py --check`
exits non-zero when it is stale.

## Environment variables

Both are optional. They are read **on every request** from `env` (Module Workers
receive `env` in `fetch`, not at module top level), so changes in the dashboard
take effect without a code redeploy.

| Variable | Format | Default |
|---|---|---|
| `ALLOWED_ORIGINS` | comma-separated browser origins | `https://elektrifikasyon.org,https://www.elektrifikasyon.org` |
| `SITE_URL` | absolute URL, no trailing slash needed | `https://www.elektrifikasyon.org` |

## Behaviour

- **Origin allowlist** — the `Origin` header is required and must be in
  `ALLOWED_ORIGINS`, otherwise `403`. `localhost` is deliberately not in the default
  list; add it only on a dev/staging deployment via `ALLOWED_ORIGINS`.
- **Rate limit** — 150 requests per 10 s per client IP (`CF-Connecting-IP`), sliding
  window, kept in isolate memory (so per isolate, not global). Over the limit:
  `429` with `Retry-After: 10`.
- **Rounding** — the API never returns more precision than the UI shows: ktoe values to
  the nearest 10, shares to 4 decimals, TWh to 1 decimal.
- **Routes** — `GET /api/model`, `/api/aile/egriler`, `/api/otomobil/model`,
  `/api/hane/model` (all accept `?lang=tr|en`); `POST /api/hesap` `{shares, subs}`,
  `POST /api/otomobil` `{sigma}`, `POST /api/hane` `{sigma}`. Anything else under
  `/api/` is `404`; `OPTIONS` preflight returns `204`.

## Local development

`tools/dev_api_server.py` (port 8816) serves the static site from `docs/` and a **Python mirror of
`worker/src`** with the same routes and rounding, so the pages can be tested without
Cloudflare. It is a hand-maintained copy: **whenever `src/model-data.js` or the logic in
`src/index.js` changes, update the Python mirror too**, then re-run the bundler.
